# 华商意大利法税顾问

面向在意大利经商的华人老板的法律与财税 AI 咨询网站。用中文提问，AI 先查本地知识库（从意大利官方网站抓取的通函、通知、新闻），不够再联网核实，然后用中文给出结论、依据、操作步骤和期限，并标注出处。

目前是跑通产品逻辑的第一版：只在本机运行，用的是本机 Claude Code 的订阅额度，不需要 API Key。

## 使用

前提：本机已安装并登录 Claude Code（终端里运行 `claude` 能正常对话），Node.js 22.5 以上。

```
npm install
npm run crawl      # 从官网抓取资料，建立本地知识库（首次约 3 分钟）
npm start          # 启动网站，打开 http://localhost:4650
```

不开网页直接问一个问题：

```
npm run ask -- "forfettario 的营业额上限是多少？"
```

## 工作方式

```
官方网站 ──抓取──▶ data/kb.sqlite（全文索引）
                        │
用户中文提问 ──▶ Claude ─┼─ search_kb / read_doc   检索本地知识库（AI 自己把问题改写成意大利语关键词）
                        └─ WebSearch / WebFetch   知识库不够时联网，优先官方来源
                        │
                 中文答案 + 出处链接（流式显示）
```

| 文件 | 作用 |
| --- | --- |
| `src/sources.mjs` | 数据源清单。加新来源只改这里 |
| `src/crawl.mjs` | 抓取器：RSS / 列表页 → 网页或 PDF 正文 → 入库 |
| `src/db.mjs` | SQLite 表结构、切块、入库 |
| `src/kb.mjs` | 检索（BM25 全文检索） |
| `src/agent.mjs` | AI 的角色设定、可用工具、调用 Claude |
| `src/server.mjs` | 网站后端（咨询接口为 SSE 流式） |
| `public/` | 前端页面 |

## 数据源

税务局通函与决议、财政司、INPS（通函 / 通知 / 新闻）、INAIL、劳动部、劳动监察局、移民融合门户、企业部（新闻 / 补贴）、政府公报。

抓取命令：

```
npm run crawl                      # 全部来源，已抓过的自动跳过
npm run crawl -- inps-news         # 只抓指定来源
npm run crawl -- --refresh         # 全部重抓
npm run crawl -- --probe 来源ID    # 只看会抓到哪些链接，不入库（调试新来源）
```

网页侧栏的“更新”按钮做的是同一件事。

## 配置（环境变量）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | 4650 | 网站端口 |
| `ADVISOR_MODEL` | claude-opus-5-5 | 使用的模型 |
| `ADVISOR_USE_API_KEY` | 未设置 | 设为 1 时改用 `ANTHROPIC_API_KEY` 按量计费，而不是订阅额度 |
| `KB_PATH` | data/kb.sqlite | 知识库文件位置 |

## 已知限制

- **只能本机自用。** 服务只监听 127.0.0.1，用的是个人 Claude 订阅。要给别人用，需要换成 Anthropic API 计费，并加上登录、限流和对话存档。
- **INPS 通函和通知只有编号与主题摘要**，正文由页面脚本动态加载，目前抓不到；政府公报也只有目录摘要。AI 遇到需要细节的情况会联网查。
- **知识库以近期文件为主**（每个来源最近 10–40 篇，共约 200 篇），覆盖不到的基础规定靠联网补。
- **检索是关键词匹配**，不是向量语义检索。靠 AI 把问题改写成意大利语术语并多次检索来弥补，资料量大了以后建议加向量检索。
- 对话历史只在当前页面里，刷新即清空。
- 回答仅供参考，不构成法律或税务意见。
